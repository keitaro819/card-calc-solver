# Card Calc Solver

5枚の手札カードと目標値（TARGET）から、四則演算（`+`, `-`, `×`, `÷`）を用いて**5枚すべてのカードを使い切り**、TARGETを導き出す計算パズルの高速ソルバー＆解法アナライザーです。

単に解を見つけるだけでなく、**「計算の芸術性・意外性」**を独自にスコアリングし、最もスマートで美しい解法から順にランキング表示します。

---

## 🌟 主な機能

- **高精度スクリーンショット自動認識**:
  - ゲーム画面のスクリーンショットを貼り付け（<kbd>Ctrl</kbd>+<kbd>V</kbd>）、ドラッグ＆ドロップ、またはファイル選択するだけで、TARGETと5枚の手札カードを自動認識して即座に入力。
- **全5枚使用解法の完全探索**:
  - すべての数式構造と演算子の組み合わせを網羅的に計算し、目標値に合致するすべての解法を瞬時に算出。
- **芸術性スコアリング（ランキング表示）**:
  - 途中式で3桁の大きな数を作ってから割る鮮やかな解法（3桁除算）、左右並行で計算を合体させる対称ツリー構造、加減乗除の多様性などを評価し、高評価順（S〜Dランク）で一覧表示。
- **問題難易度判定**:
  - 解法のパターン数に応じて問題の難易度（★1〜★5）を自動判定。パターン数が少ない問題ほど難易度が高く、たった1通りしかない問題は「最難関 ★★★★★」となります。
- **直感的なステップ＆バリエーション表示**:
  - 1手ごとの計算手順や、等価な計算順序バリエーションをアコーディオン展開して確認可能。
- **URLパラメータ対応**:
  - URLのクエリパラメータで問題を直接指定・復元可能。現在の盤面がアドレスバーに自動反映されるため、URLをコピーするだけで問題を共有できます。

---

## 🚀 使い方

### 1. スクリーンショットから自動入力
1. ゲーム画面のスクリーンショットをクリップボードにコピーした状態で、画面上で <kbd>Ctrl</kbd>+<kbd>V</kbd>（Macは <kbd>Cmd</kbd>+<kbd>V</kbd>）を押すか、枠内に画像をドロップします。
2. 画像認識が完了すると、TARGETと5枚のカードが自動セットされ、画面が「TARGET & カード数値」位置へスムーズスクロールして解法一覧が表示されます。

### 2. 数値を直接手動入力
- **TARGET**: 目標となる数値を入力します。
- **カード (5枚)**: 5枚の手札数値を各枠に入力します。
  - 数字を入力すると次の枠へ自動フォーカス移動します。
  - キーボードの <kbd>→</kbd> / <kbd>←</kbd> や <kbd>Enter</kbd> で前後の枠にすばやく移動できます。

### 3. 解法一覧の確認
- 芸術度スコアの高い順に解法が表示されます。
- 「手順を展開」で1手ずつの計算の流れを確認できます。
- 同一構造で計算順序が異なるバリエーションが存在する場合、バリエーション欄を展開して確認できます。

## 🔗 URLパラメータ仕様

URLにパラメータを付与することで、ページアクセス時に特定の問題を直接ロード・計算できます。また、画面上で数値を変更したりスクショを読み込んだ際にも、アドレスバーのURLパラメータが自動更新されるため、そのままURLを共有できます。

### 1. パラメータ一覧

| パラメータ名 | 省略形 | 説明 | 指定例 |
| :--- | :--- | :--- | :--- |
| `target` | `t` | 目標値（TARGET）となる数値 | `target=31` または `t=31` |
| `cards` | `c` | 5枚の手札カードの数値（区切り文字対応） | `cards=6,1,1,4,5` または `c=6,1,1,4,5` |
| `c1` 〜 `c5` | `card1` 〜 `card5` | 5枚のカードを1枚ずつ個別に指定 | `c1=6&c2=1&c3=1&c4=4&c5=5` |

### 2. 区切り文字のサポート
`cards`（または `c`）パラメータでは、カンマのほかハイフン、スペース、アンダースコア、スラッシュなどの区切り文字に対応しています。
- カンマ区切り: `?target=31&cards=6,1,1,4,5`
- ハイフン区切り: `?target=31&cards=6-1-1-4-5`
- スラッシュ区切り: `?target=31&cards=6/1/1/4/5`

### 3. URL例

- **基本形**:
  ```text
  https://example.com/?target=31&cards=6,1,1,4,5
  ```
- **短縮形**:
  ```text
  https://example.com/?t=31&c=6,1,1,4,5
  ```
- **別解の多い例**:
  ```text
  https://example.com/?target=24&cards=1,2,3,4,6
  ```

### 4. URLアクセス時の動作
- 指定されたTARGETと5枚のカードが即座にセットされ、解法一覧が自動計算されます。
- 初期読み込み後、見やすいように「TARGET & カード数値」の位置まで自動でスムーズスクロールします。
- ブラウザの「戻る」「進む」履歴にも連動しています。

## 🎨 芸術性スコア（採点基準）

計算式の美しさと鮮やかさを100点満点で評価しています。

- **👑 3桁除算（最高峰 / +45点）**:
  - 計算途中で100以上の大きな数を作り、割り算（÷2以上）で一気に目標値へ着地する妙技。
- **🌲 左右対称ツリー構造（+30点）**:
  - `(AとB) と (CとD)` を左右並行で同時に計算し、最後に中央で合体させる美しいトーナメント構造。
- **⚡ 3桁到達・迂回（+20点）**:
  - 1桁のカードから途中で100以上の大きな数へ大胆に引き上げてから目標値へ戻るルート。
- **✖️ 12以上×2以上の掛け算（最大+20点）**:
  - 計算順序によらず、12以上×2以上の二桁掛け算を組み込むテクニック。
- **🎨 演算子の多様性（+10〜20点）**:
  - 加減乗除の4種すべてを駆使（+20点）または3種使用（+10点）。
- **✨ 0・1の意図的な生成（各+5点）**:
  - 引き算や同一数同士の割り算（N÷N）で自前で「0」や「1」を作り出し、手札を美しく整理する工夫。

## 🔥 難易度判定の基準

全5枚を使用した正解パターンの数に基づき、問題自体の難易度を判定しています。

| 難易度ランク | 正解パターン数 | 特徴 |
| :--- | :--- | :--- |
| **最難関 ★★★★★** | 1通り | 正解がたった1つしかない超難問。唯一無二のひらめきが必要。 |
| **難問 ★★★★☆** | 2〜3通り | 解法がごくわずかしか存在しない高難度問題。 |
| **上級 ★★★☆☆** | 4〜10通り | 解法パターンが限られており、適度な試行錯誤が必要。 |
| **中級 ★★☆☆☆** | 11〜30通り | 複数の解法アプローチが存在する標準的な難易度。 |
| **初級 ★☆☆☆☆** | 31通り〜 | 解法が豊富で解きやすい入門レベルの問題。 |
| **解なし** | 0通り | 5枚すべてを使い切る解法が存在しない問題。 |

※画面上の難易度バッジをタップすることで、いつでもこの判定基準Tipsを展開できます。
